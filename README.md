# CPS Universal Downloader — Release Index

This branch is the public release index for CPS Universal Downloader.

- The complete public Basic v1.3.0 source remains on the `main` branch and the
  `v1.3.0` tag.
- Starting with v1.3.1, this branch contains release metadata only. It does not
  contain Premium, licensing, DRM, plugin, or private service source code.
- Installers, portable builds, release notes, and checksums are published on the
  [Releases](https://github.com/Chuobpiseth/cps-universal-downloader-basic/releases)
  page.

Download media only when you own it or have permission to save it.

## Release process

Future public release tags are created from this branch so GitHub's automatic
source archive contains only this public metadata. Application source for
versions after v1.3.0 is maintained separately under its applicable license.
