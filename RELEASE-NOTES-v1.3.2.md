# CPS Universal Downloader 1.3.2

This update improves the desktop controls and download management.

- Fixed an invisible assistant area that could block buttons on Home, Downloads, History, and Convert.
- Fixed completed-download file-location and remove actions, with clearer feedback.
- Kept the file and remove actions reachable when the app window is narrow.
- Refreshed the Home and sidebar branding and platform artwork.

Download the Windows installer or portable app from this release. SHA-256 checksums are in `SHA256SUMS-v1.3.2.txt`.
