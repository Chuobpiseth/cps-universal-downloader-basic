# CPS Universal Downloader Basic v1.3.0

Version 1.3.0 is the final public Basic source snapshot.

Highlights:

- Public video and image download workflows for supported platforms.
- Playlist analysis and manual item selection.
- Browser-extension integration through an authenticated local connection.
- Download queue, history, conversion, AI tools, and bilingual UI improvements.
- Update feed migrated to the public Basic repository.

The corresponding source is available from the `v1.3.0` tag on the `main`
branch. Future public releases use this branch only as a release index.
